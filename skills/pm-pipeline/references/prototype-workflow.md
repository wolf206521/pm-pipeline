# 原型并行生成工作流(prototype-workflow)· 多代理/多模块量产与集成

> 适用:几十~几百个原型页面的批量生成。单页深度规范见 prototype-depth.md,行为验证见 interaction-testing.md,本文件是「怎么批量造、怎么集成、怎么不出事」。

## 八步工作流(已验证)

1. **读约束**:规则总册(rules-registry)+ PRD + 演示数据集,任何代理开工前必读
2. **分组并行**:按子模块分组,每组一个代理;**每组独立数据文件**(demo-data 按组拆分,防写冲突)
3. **统一命名表**:文件名/侧栏链接先出统一命名表,各组照表链接;没有表就按「实际文件名」回扫对齐(并行自推导必然分歧,本轮 175 处死链的教训)
4. **静态回归**:七层机检全绿才进下一步
5. **行为回归**:交互运行器全操作点测(见 interaction-testing.md)
6. **视觉评审**:全页截图,分组走查(布局/规则/深度/数据合理性)
7. **覆盖审计**:PRD↔页面五维核对,遗漏补齐,超出项人工裁决
8. **修复迭代→全绿收官**:修一轮跑一轮,直到静态+行为双零失败

## 事故纪律(真实事故沉淀,必须遵守)

| 纪律 | 来源事故 |
|---|---|
| 批量脚本先单页试跑+改前快照 | 正则回调错误抽空 101 页 href |
| 产物无版本库时建里程碑快照 | 页面误删无法恢复 |
| 共享资源链接加版本参数(?v=日期) | 浏览器缓存损坏期旧 js,页面「功能失效」实为缓存 |
| 测试工具先自证再证页面 | 运行器自身 bug 报 265 个假 404/归因错乱 |
| 规则表述精确,防一刀切 | 「去重」被扩大成「全删」,创建类入口误删 |
| 临时产物当日清理(探针页/临时运行器) | 临时文件混入静态扫描报假失败 |

## 数据一致性纪律

- 演示数据唯一事实源:数据集文件(demo-data/*.js),页面渲染引用+运行时断言(checkPage)
- 跨页同一对象:编号/金额/状态/版本必须与数据集互洽;评审最爱抓「头尾不一」
- 锚点登记表(页面→断言值)以页面实际渲染为准,不以登记为准

## 容量参考(本轮实测)

- 6 组并行,62 页/轮,真实行业数据,26+ 条规则约束
- 集成修复:175 处链接统一,静态+行为双零失败收官
