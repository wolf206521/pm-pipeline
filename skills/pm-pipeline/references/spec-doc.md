# 开发说明书(S4.5 阶段)· 页面级施工规格

> 适用:原型确认后、代码开发前,把 PRD(实体级)+流程图(流转)+原型(视觉)拼成开发可直接施工的页面级规格。解决「开发自己拼五份文件必拼错」的问题。

## 定位与节奏

- **时机**:全部原型完成并 G4 确认后统一产出
- **节奏纪律**:原型未完成未确认前,不补充、不生成任何说明文档;S4 原型阶段只出页面
- **粒度**:每模块一份 `spec/v0.1.md`,按业务与功能点分节(功能点≈页面/页面组,与 RTM 的 US 行对齐)

## 固定五段结构(每个功能点一节)

1. **概述**:用途/角色入口/权限
2. **区块结构与字段表**:区块命名对齐原型规范;字段只写「引用 PRD §x.x 字段名 + 本页特有说明」
3. **交互规格**:每个操作的 触发条件 → 状态流转(状态码) → 事件 → 接口契约(含幂等键)
4. **异常与空态**:异常码引用 + 页面表现(空/错/加载/无权限)
5. **埋点**:事件名/触发时机/字段

## 单一事实源纪律(防双头)

| 内容 | 唯一事实源 | 说明书中 |
|---|---|---|
| 字段定义(类型/边界/校验) | PRD 字段字典 | 只引用+页面级补充 |
| 状态枚举 | 全局状态基线 | 只引用状态码 |
| 呈现规则 | 规则总册 | 不重复 |
| 接口契约细节 | 说明书 | 此处为权威(含幂等键) |

## 机检

- 模块存在 spec 文件后:RTM 该模块全部页面锚点必须在说明书中出现(覆盖核查)
- 说明书引用的状态码/事件编码须与状态基线/事件登记表一致

## 交付边界

- 本管线只交付需求侧产物:RTM/PRD/流程图/原型/页面说明书/导出文档
- 技术架构、数据模型(ER/表结构)、NFR 属开发团队职责;其产出以本管线产物为输入,涉及需求口径变更必须回流走改版流程,不得旁路修改
