# CONVENTIONS · 命名与版本规则(通用模板)

## 模块编号

沿用需求大纲编号:`<模块编号> <模块名>`(如 `M00 通用中心`)。以 `01-记忆/` 中的模块清单文件为准。

模块目录名:`<模块编号>-<模块名>`,如 `M02-客服中心`。

## 版本规则

- PRD / 流程图 / 原型都按 `v0.<n>` 递增,每过一次确认点 +0.1
- 确认定稿后为 `v1.0`,定稿后再改走 `v1.1` 并记录变更原因
- 文件内第一行写:`版本 v0.3 | 日期 | 基于 v0.2 的改动:xxx`
- 不删除旧版本文件,新版本另存

## 文件命名

| 产物 | 命名 | 例 |
|---|---|---|
| 需求摘要 | `02-需求输入/<模块编号>-<模块名>.md` | `M02-客服中心.md` |
| PRD | `prd/v0.<n>.md` | `prd/v0.1.md` |
| 流程图源码 | `flows/<流程名>.mmd` | `flows/工单流转.mmd` |
| 流程图说明 | `flows/<流程名>.md` | `flows/工单流转.md` |
| 原型页面 | `prototype/<页面名>.html` | `prototype/ticket-create.html` |
| 确认记录 | `review/<日期>-G<n>.md` | `review/2026-01-08-G2.md` |
| 交付 docx | `20-交付/<项目代号>_<模块编号>_<模块名>_PRD_v<x.y>.docx`(`export_docx.py --prefix <项目代号>`) | `PROJ_M02_客服中心_PRD_v1.0.docx` |

## 引用源资料

引用源文件时写全路径 + 文件名,如:`源:/path/to/<模块说明书>V1.2.docx`。源文件只引用不修改。

## 日期格式

一律 `YYYY-MM-DD`。
