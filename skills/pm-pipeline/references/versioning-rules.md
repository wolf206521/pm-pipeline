# 版本化管理规则(versioning-rules)· 通用版本化对象口径

> 适用:任何「会随时间产生多个版本、旧版本仍有追溯/引用价值」的业务对象——文件、报价、合同、规则族(工艺/路线/公式/审批流/模板/参数)、设备主档、指标口径、数据集、模型等。

## 判定标准(满足任一即版本化对象)

- 对象随时间产生多个版本,旧版本仍有追溯/引用价值
- 对象被业务单据引用后不得覆盖(引用冻结)
- 业务上有「当前有效版本」与「历史版本」之分

## 统一规则 V1–V7

| # | 规则 | 说明 |
|---|---|---|
| V1 | 历史留痕不可删 | 旧版本只读保留;修改/更正只能新建版本(或新增冲正/修订记录),不得覆盖 |
| V2 | 当前有效版本唯一 | 同一对象同一时刻仅一个当前有效版本;切换记录操作人/时间/原因 |
| V3 | 版本标识清晰 | 版本号规则明确(整数 Vn 或语义化 x.y.z),新号递增;编码发布后不复用 |
| V4 | 历史可查看可对比 | 版本历史列表(版本/关键值/状态/时间/生成方式),旧版本可查看快照、可对比 |
| V5 | 生效与失效显式 | 生效/失效时间、替代关系显式记录;回滚生成回滚记录(前后版本/原因/操作者) |
| V6 | 引用快照不回写 | 已被单据引用的版本固化快照,后续版本变更不回写历史单据 |
| V7 | 终态保护 | 已锁定/已确认/已归档版本不得删除覆盖;恢复=复制为新版本(标记来源「由 Vn 恢复」) |

## 原型呈现映射(与呈现规范配套)

- 版本历史区块:当前版本行视觉突出;版本切换必须真切换内容(禁只弹提示)
- 详情页头部当前版本 = 历史表「当前版本」行(可机检)
- 列表页版本列只显示版本号(当前有效版本唯一,无需标注)
- 「新建版本」是版本化对象的标配编辑入口(编辑已生效对象=复制为新版本草稿)

## 自检建议

- 维护版本化对象清单(对象/权威方/要点);扫描各模块 PRD 版本语义关键词与清单交叉,未登记即报「需求发现」
- 跨页一致性:同一对象在不同页面的版本号/金额/状态必须互洽
